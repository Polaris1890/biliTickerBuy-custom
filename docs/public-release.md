# 公开发布说明

本仓库基于上游 `v2.15.18` 的源码，保留版权声明和 `LICENSE`，以干净源码快照建立公开提交历史。上游旧提交历史没有导入本公开仓库。

## 发布内容

- 程序源码、测试、构建配置、依赖版本与安装文档。
- Windows EXE 安装 ZIP、源码 ZIP、中文安装说明及 SHA256 校验清单。

## 隐私检查

公开前对提交历史、源码归档和 Windows 安装包中的文件进行了检查，并与维护者本机的实际登录及票务资料作匹配检查。

公开内容不包含维护者的 Cookie、登录凭据、手机号、证件资料、收货地址、个人购票配置、运行日志、实际使用截图或本机用户目录。

TLS 握手模块中保留一条经核实的 Python 类型注解，它只描述运行时临时生成的密钥对象，不包含固定密钥或认证凭据。该行的扫描标记仅对应这条类型注解。

示例及测试使用虚构数据。`.gitignore` 排除了运行配置、临时目录、日志、备份文件和本地环境变量文件；发布时只归档版本控制中的源码，安装包只包含 EXE、安装说明、构建信息和许可证。

使用者仍需在自己电脑上扫码登录并生成票务配置。生成的文件和登录数据应留在本机，不要添加到 Git 或发布附件中。
